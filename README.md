# Python Games 


A collection of **fun command-line Python games** designed for learning and entertainment!  

This repository currently includes:

| Game | Description |
|------|-------------|
|  **Rock-Paper-Scissors** | Challenge the computer in the classic rock-paper-scissors game. |
|  **Tic-Tac-Toe** | Two-player game where X and O compete to align 3 marks. |

---

##  Features

- Simple and interactive command-line interface (CLI) games  
- Easy to run and modify for Python beginners  
- Great for learning Python loops, conditions, and functions

## How to play

# Rock-Paper-Scissors
```bash
python rock_paper_scissors.py
```
- Choose rock, paper, or scissors.
- Play against the computer.
- Rock beats scissors, scissors beats paper, paper beats rock.

# Tic-Tac-Toe
```bash
python tictactoe.py
```
- Two players take turns marking X and O.
- First player to align 3 marks in a row, column, or diagonal wins.
